01

枚方の図書館網THE NETWORK

枚方市の図書館は、ひとつの大きな館にすべてを集める形ではなく、市内に細かく散らして、どこに住んでいても歩いて行けるという考え方で作られています。淀川沿いの平地から東の丘陵地まで市域が広く、生活圏がいくつにも分かれている土地だからです。

その結果が、中央図書館1館・分館7館・市駅前図書館1館という9つの図書館と、6つの分室、そして本を積んで巡回する2台の自動車文庫「ひなぎく号」「カワセミ号」という布陣。貸出カードは共通で、どの館で借りてどの館で返してもかまいません。予約した本を受け取る場所も選べます。

02

9つの図書館NINE LIBRARIES

中央図書館と市駅前図書館、そして7つの分館。それぞれ性格が違います。

中央図書館

枚方市立中央図書館

市内最大の蔵書を持つ、枚方の図書館の中枢。輝きプラザきらら内にあり、点字図書や録音図書の製作・貸出も担っています。調べ物や、市内のどこかにある一冊を取り寄せる拠点として使う館です。

ほかの館と違い金曜が休館、閉館も19時と早めなので、思い立って行く前にカレンダーの確認を。

車塚2丁目1-1／050-7105-8141
京阪御殿山駅から徒歩約15分　地図

市駅前図書館

枚方市立市駅前図書館

2024年9月開館。枚方市駅直結のステーションヒル枚方5階にあり、生涯学習交流センターとの複合施設です。約2万冊と規模は小さいものの、日曜・祝日も21時まで開いているのはここだけ。

木を模した柱が並ぶ「ボタニカル」がテーマの明るい空間で、交流スペースがゆったり取られています。仕事帰りや買い物ついでに寄る館。

岡東町19-1（ステーションヒル枚方5階）／072-841-1103
京阪・JR 枚方市駅直結　地図

分館

香里ケ丘図書館

2020年7月に建て替えでリニューアルした、分館のなかの目玉。閲覧スペースは以前の約2倍、蔵書は約10万冊まで増えました。自習室は1階11席・2階32席の計43席と、市内でも屈指の充実ぶり。

隣の香里ケ丘中央公園の一部を「みどりの広場」として図書館と一体で運営していて、2階から直接ブリッジで出られます。本を持って外で読める分館です。

走る図書館「ひなぎく号」「カワセミ号」

枚方市には自動車文庫が2台あります。本を積んで市内の巡回地点をまわる、いわば動く分室です。図書館から遠い地区や、坂の多い地域に住む人にとっては、これがいちばん近い図書館になります。

巡回の場所と日時は決まっているので、近所に停まる日があるかどうかは公式サイトの巡回予定で確認してみてください。拠点は中央図書館（050-7105-8114）です。

覚え方はひとつだけ

「金曜は中央が休み、そのぶん分館は21時まで開いている」。金曜の夜に本が必要になったら、中央ではなく分館か市駅前へ。逆に第4月曜は分館と市駅前が休みで、中央が開いています。うまく補い合う設計になっています。

05

目的別・今日はどこへWHICH ONE TODAY

  • じっくり調べ物をしたい → 中央図書館。市内最大の蔵書で、ここで見つからなければ府立図書館へ取り寄せる相談ができます。
  • 仕事帰りに寄りたい → 市駅前図書館。駅直結で毎日21時まで。分館も土曜まで21時まで開いています。
  • 休日に子どもと過ごしたい → 香里ケ丘図書館。隣接の「みどりの広場」へ2階から直接出られるので、本と外遊びを行き来できます。
  • 自習したい → 香里ケ丘図書館の自習室（1階11席・2階32席）。
  • 予約した本を受け取るだけ → いちばん近い分室で十分。6か所どこでも受け取れます。
  • 日曜の夕方に借りたい → 市駅前図書館。日祝も21時までなのはここだけです。

旅の起点として

このサイトは枚方を起点に全国の図書館をめぐる記録です。遠出の前に中央図書館で旅行ガイドや時刻表を借りて、帰ってきたら市駅前図書館で写真を整理する——地元の図書館は、旅の始まりと終わりの場所でもあります。
